# paper-desk

AI-assisted academic writing desk. Students submit a brief and materials; the service produces an outline, a first draft, revision suggestions and citation/format cleanup, with a human review step before delivery.

Status: early scaffold.

## Scope

- Writing assistance only. Output is a draft and revision aid for the student to work from, not a finished paper for submission.
- Order flow: submit brief → automatic assessment → confirm → AI draft → human review → delivery (free revisions on request).
